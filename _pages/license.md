## Licensing

Each project and product may use a different license. Always check the license file in the corresponding repository and the statement on the product page. Purchasing a physical product or a packaged file bundle does not transfer copyright and does not grant any rights beyond those in the stated license.

## Design files and digital content

Where design files are offered, the product page states which files are included, which versions they apply to, known limitations, permitted use and the update policy. Some screenshots and documents published in the engineering notes are provided for documentation only and are not themselves licensed as reusable design files. This Site currently has no automated download or checkout.

## Physical hardware

Hardware is supplied as described on its product page. Availability, package contents, dispatch arrangements, warranty and defect handling are confirmed in writing before an order is placed. Listings currently show **price on request**. Payment is handled by a separately linked checkout provider; this Site does not collect or store payment card details.

## Enquiries, corrections and after-sales

For licensing questions, file access problems, order enquiries or defect reports, email [bi4wms@gmail.com](mailto:bi4wms@gmail.com) or use the [Contact page](/contact/). Include the product or repository name and, for hardware, the board revision so we can help quickly.

## Scope of this page

This page is general information about how the lab publishes and supplies its work; it is not legal, tax or compliance advice. See also the [Privacy Policy](/privacy/) and [Disclaimer](/disclaimer/).

## 授权

每个项目、每件商品可能适用不同的许可证。请始终以对应仓库中的许可证文件以及商品页上的说明为准。购买实体产品或打包文件不会转移著作权，也不会授予超出该许可证范围的权利。

## 设计文件与数字内容

如提供设计文件，商品页会说明包含哪些文件、适用的版本、已知限制、允许的使用方式与更新政策。工程笔记中发布的部分截图与文档仅用于说明，本身并不作为可复用的设计文件授权。本站目前没有自动下载或在线结算功能。

## 实体硬件

硬件按商品页描述提供。供货情况、随附内容、发货安排、质保与不良品处理，会在下单前以书面形式确认。当前商品均标注为**询价**。付款由单独链接的外部结算平台处理，本站不收集或保存银行卡信息。

## 咨询、勘误与售后

授权问题、文件获取异常、订单咨询或不良品反馈，请发邮件至 [bi4wms@gmail.com](mailto:bi4wms@gmail.com)，或使用[联系页面](/contact/)。来信请注明项目或商品名称；涉及硬件时附上板卡版本号，便于我们尽快处理。
